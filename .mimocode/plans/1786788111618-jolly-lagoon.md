## Изменения

### 1. `list.html` — заголовок сразу после кнопок
Текущий макет: кнопки слева, h1 по центру (flex:1).
Новый: всё в одном flex-контейнере, h1 сразу после кнопок:
```html
<div class="page-header" style="gap:1rem; flex-wrap:wrap;">
    <div style="display:flex; align-items:center; gap:0.75rem;">
        <a>+ Создать ТКП</a>
        <button>Сбросить фильтры</button>
        <h1>Реестр ТКП</h1>
    </div>
    <span>Всего: N</span>
</div>
```

### 2. `list.html` — высота строк
Строка 124: `min-height: 2.6em; height: 2.6em;` — уже стоит, подтверждено.

### 3. `style.css` — sidebar не сворачивается
Текущее состояние: sidebar 24px, расширяется до 200px при `:hover`, текст скрыт через `opacity:0`.
Нужно:
- Убрать `.sidebar:hover { width: 200px }` и связанные hover-правила
- Поставить фиксированную ширину ~160px
- Убрать `overflow: hidden`, `opacity: 0` для nav-текста
- Обновить `margin-left` у `.main-content` на 160px
- Убрать `writing-mode: vertical-rl` у `.brand` (sidebar больше не узкий)
