## 3. Email notification on registration

**Files to modify:**
- `config.py` — add `MAIL_TO_REPORT: str = ""`
- `scr/utils/email.py` — new file, async email sender
- `scr/Routers/auth.py` — send email after successful registration
- `scr/Routers/pages.py` — send email after successful registration

**`scr/utils/email.py`:**
```python
import asyncio
import smtplib
from email.mime.text import MIMEText


async def send_registration_notification(user_email: str, user_name: str):
    """Send notification about new registration to MAIL_TO_REPORT."""
    from config import settings
    from scr.dbase.database import db_helper
    from scr.dbase.crud_settings import get_setting

    if not settings.MAIL_TO_REPORT:
        return

    async with db_helper.session_factory() as session:
        smtp_host = await get_setting(session, "smtp_host") or ""
        smtp_port = int(await get_setting(session, "smtp_port") or "587")
        smtp_user = await get_setting(session, "smtp_user") or ""
        smtp_password = await get_setting(session, "smtp_password") or ""
        smtp_from = await get_setting(session, "smtp_from") or ""

    if not smtp_host:
        return

    msg = MIMEText(f"Зарегистрирован новый пользователь:\nИмя: {user_name}\nEmail: {user_email}", "plain", "utf-8")
    msg["Subject"] = "Новая регистрация"
    msg["From"] = smtp_from
    msg["To"] = settings.MAIL_TO_REPORT

    def _send():
        with smtplib.SMTP(smtp_host, smtp_port) as server:
            if smtp_user:
                server.starttls()
                server.login(smtp_user, smtp_password)
            server.send_message(msg)

    await asyncio.to_thread(_send)
```

- Call `send_registration_notification` after `session.commit()` in both `auth.py:register` and `pages.py:register_submit`
- Wrap in try/except to not break registration if email fails (log the error)
- No new dependencies needed (smtplib is stdlib)
