# MVP Приложение регистрации запросов

## Цель проекта

Создать веб-приложение для регистрации входящих запросов на предприятии с базовой функциональностью и подготовкой к интеграции ИИ.

---

## Стек технологий

- **Backend**: FastAPI + Django Ninja
- **Database**: SQLite
- **Frontend**: рендеринг страниц через Ninja templates

---

## База данных (модели)

Создайте следующие таблицы в PostgreSQL:

### Position (Должность)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| name | string | Название должности (не пусто, уникально) |
| created_by | string | ФИО пользователя, создавшего запись (заполняется автоматически из сессии) |
| created_at | timestamp | Дата создания |

**Предустановленные значения**: Директор, Генеральный директор, Финансовый директор

### Director (Директор)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| name | string | ФИО директора (не пусто) |
| position_id | Foreign Key | Ссылка на Position (не пусто) |
| created_by | string | ФИО пользователя, создавшего запись (заполняется автоматически из сессии) |
| created_at | timestamp | Дата создания |
| updated_at | timestamp | Дата обновления |

### Manager (Менеджер)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| name | string | ФИО менеджера (не пусто) |
| email | string | Email менеджера (уникально) |
| phone | string | Контактный телефон |
| city | string | Город/код города (по умолчанию: "ив") |
| created_by | string | ФИО пользователя, создавшего запись (заполняется автоматически из сессии) |
| created_at | timestamp | Дата создания |
| updated_at | timestamp | Дата обновления |

### Counterparty (Контрагент)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| name | string | Не пусто |
| email | string | Уникально |
| phone | string | Контактный телефон |
| company_id | Foreign Key | Ссылка на Company (не пусто) |
| created_by | string | ФИО пользователя, создавшего запись (заполняется автоматически из сессии) |
| created_at | timestamp | Дата создания |
| updated_at | timestamp | Дата обновления |

### Company (Компания)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| name | string | Название компании (не пусто) |
| inn | string | ИНН компании (уникально) |
| address | text | Адрес |
| server_address_slug | string | Слаг адреса на сервере (по умолчанию: "/02_сторонние_заказчики") |
| director_id | Foreign Key | Ссылка на Director |
| created_by | string | ФИО пользователя, создавшего запись (заполняется автоматически из сессии) |
| created_at | timestamp | Дата создания |
| updated_at | timestamp | Дата обновления |

### Request (Запрос)

| Поле | Тип | Описание |
|------|-----|---------|
| id | UUID/Integer | Primary key |
| counterparty_id | Foreign Key | Ссылка на Counterparty (не пусто) |
| company_id | Foreign Key | Ссылка на Company (заполняется автоматически по связке counterparty_id) |
| manager_id | Foreign Key | Ссылка на Manager (заполняется автоматически из сессии) |

## API Endpoints (FastAPI)

### GET /api/requests

Получить список всех запросов

**Параметры**:
- `status` (optional) — фильтр по статусу
- `counterparty_id` (optional) — фильтр по контрагенту
- `company_id` (optional) — фильтр по компании
- `manager_id` (optional) — фильтр по менеджеру
- `date_from` (optional) — дата начала периода
- `date_to` (optional) — дата конца периода
- `page` (optional) — номер страницы (default: 1)
- `per_page` (optional) — количество результатов на странице (default: 20)

**Возвращает**: список запросов с информацией о контрагенте, компании и менеджере

### POST /api/requests

Создать новый запрос

**Требуемые поля**:
- `counterparty_id`
- `description`

**Автоматически заполняемые поля**:
- `company_id` (по связке counterparty_id)
- `manager_id` (из сессии текущего пользователя)
- `request_date` (текущее время)
- `created_by` (из сессии текущего пользователя)
- `tkp_num` (формируется как "{id}-{city}", где city из профиля менеджера)

**Опциональные поля**:
- `status` (default: 'запрос')
- `notes`
- `bktpb`, `ktpb`, `ktp`, `kso_393`, `kso_204`, `k_104`, `k_104m`, `sho`, `pku`, `pus`, `parn` (default: 0)

**Возвращает**: созданный запрос с id

### GET /api/requests/{request_id}

Получить детали запроса

**Возвращает**: полную информацию о запросе, контрагенте, компании и менеджере

### PUT /api/requests/{request_id}

Обновить запрос

**Может обновлять все поля кроме**:
- `id`
- `created_by` (защищено)
- `created_at` (защищено)
- `tkp_num` (защищено, формируется один раз при создании)

**Может обновлять**:
- `counterparty_id` (компания обновляется автоматически по новой связке)
- `status`
- `description`
- `notes`
- `request_date`
- `bktpb`, `ktpb`, `ktp`, `kso_393`, `kso_204`, `k_104`, `k_104m`, `sho`, `pku`, `pus`, `parn`

**Возвращает**: обновлённый запрос

### GET /api/counterparties

Получить список контрагентов

**Параметры**:
- `company_id` (optional) — фильтр по компании
- `search` (optional) — поиск по имени/email
- `page` (optional) — номер страницы
- `per_page` (optional) — количество результатов на странице

**Возвращает**: список контрагентов

### POST /api/counterparties

Создать новый контрагент

**Требуемые поля**:
- `name`
- `email`
- `company_id`

**Автоматически заполняемые поля**:
- `created_by` (из сессии текущего пользователя)

**Опциональные поля**:
- `phone`

**Возвращает**: созданный контрагент

### GET /api/companies

Получить список компаний

**Параметры**:
- `search` (optional) — поиск по названию/ИНН
- `page` (optional) — номер страницы
- `per_page` (optional) — количество результатов на странице

**Возвращает**: список компаний

### POST /api/companies

Создать новую компанию

**Требуемые поля**:
- `name`
- `inn`

**Автоматически заполняемые поля**:
- `created_by` (из сессии текущего пользователя)
- `server_address_slug` (default: "/02_сторонние_заказчики")

**Опциональные поля**:
- `address`
- `director_id`

**Возвращает**: созданная компания

### GET /api/managers

Получить список менеджеров

**Параметры**:
- `search` (optional) — поиск по имени/email
- `page` (optional) — номер страницы
- `per_page` (optional) — количество результатов на странице

**Возвращает**: список менеджеров

### POST /api/managers

Создать нового менеджера

**Требуемые поля**:
- `name`
- `email`

**Автоматически заполняемые поля**:
- `created_by` (из сессии текущего пользователя)
- `city` (default: "ив")

**Опциональные поля**:
- `phone`
- `city`

**Возвращает**: созданный менеджер

### GET /api/directors

Получить список директоров

**Параметры**:
- `position_id` (optional) — фильтр по должности
- `search` (optional) — поиск по имени
- `page` (optional) — номер страницы
- `per_page` (optional) — количество результатов на странице

**Возвращает**: список директоров

### POST /api/directors

Создать нового директора

**Требуемые поля**:
- `name`
- `position_id`

**Автоматически заполняемые поля**:
- `created_by` (из сессии текущего пользователя)

**Возвращает**: созданный директор

### GET /api/positions

Получить список должностей

**Возвращает**: все доступные должности

### POST /api/positions

Создать новую должность

**Требуемые поля**:
- `name`

**Автоматически заполняемые поля**:
- `created_by` (из сессии текущего пользователя)

**Возвращает**: созданная должность

## Frontend (Django Ninja шаблоны)

### Главная страница (/)

**Форма входа**:
- Поле email
- Поле password
- Кнопка "Войти"

При успешной авторизации — редирект на страницу регистрации запросов.

### Страница регистрации запросов (/dashboard)

**Отображает**:
- Последние 15 записей Request (таблица)
- Кнопка "Создать новую запись"
- Информация о текущем менеджере (из сессии)

### Страница списка запросов (/requests)

**Таблица со всеми запросами**:
- Колонки: ID, TKP номер, дата, контрагент, компания, менеджер, статус, действия
- Фильтры: по статусу, дате, контрагенту, менеджеру
- Кнопка "Создать запрос"

### Форма создания/редактирования запроса (/requests/create, /requests/{id}/edit)

**Элементы формы**:
- Менеджер (отображается как readonly, автоматически заполнен из сессии)
- Выбор контрагента (dropdown с поиском)
- Компания (подтягивается по company_id контрагента, readonly)
- Дата запроса (date picker, по умолчанию: текущее время)
- Статус (dropdown с предустановленными значениями)
- Описание запроса (textarea)
- Дополнительные заметки (textarea)
- **Оборудование** (числовые поля, 0-100):
  - БКТПБ
  - КТПБ
  - КТП
  - КСО-393
  - КСО-204
  - К-104
  - К-104М
  - ЩО
  - ПКУ
  - ПУС
  - ПАРН
- Кнопки: "Сохранить", "Отмена"

### Страница деталей запроса (/requests/{id})

**Содержит**:
- Вся информация о запросе (включая TKP номер и количество оборудования)
- Информация о контрагенте и его компании (с директором)
- Информация о менеджере
- История изменений статуса
- Кнопки редактирования и удаления

### Управление контрагентами (/counterparties)

**Функциональность**:
- Список контрагентов с фильтром
- Форма добавления нового контрагента (name, email, phone, company_id)
  - **Кнопка "Создать новую компанию"** (открывает модальное окно/встроенную форму создания компании)
  - **Кнопка "Создать директора с должностью"** (открывает модальное окно/встроенную форму создания директора и должности)
- Возможность редактирования/удаления
- Название компании подтягивается по company_id

### Управление компаниями (/companies)

**Функциональность**:
- Список компаний с фильтром
- Форма добавления новой компании (name, inn, address, director_id, server_address_slug)
  - **Кнопка "Добавить нового директора"** (открывает модальное окно/встроенную форму создания директора)
  - **Кнопка "Добавить новую должность"** (открывает модальное окно/встроенную форму создания должности)
- Возможность редактирования/удаления
- Отображение директора и его должности

### Управление менеджерами (/managers)

**Функциональность**:
- Список менеджеров с фильтром поиска
- Форма добавления нового менеджера (name, email, phone, city)
- Возможность редактирования/удаления

### Управление директорами (/directors)

**Функциональность**:
- Список директоров с фильтром по должности
- Форма добавления нового директора (name, position)
- Возможность редактирования/удаления

## Требования к реализации

- Используйте **ORM (SQLAlchemy)** для работы с БД
- **Валидация данных** на backend с помощью Pydantic
- **Обработка ошибок** (404, 400, 500) с понятными сообщениями
- **CSRF защита** для форм
- **Логирование операций** (создание, обновление, удаление запросов)
- **Простой, чистый дизайн** без JavaScript-фреймворков (pure HTML/CSS)
- **Responsive дизайн** (мобильная адаптация)
- **Поле created_by** заполняется автоматически из сессии пользователя во всех моделях
- **request_date** заполняется автоматически текущей датой/временем при создании запроса
- **tkp_num** формируется автоматически при создании запроса как "{id}-{city}", где city берётся из поля city менеджера
- При выборе контрагента компания подтягивается автоматически по company_id контрагента
- При обновлении контрагента в запросе company_id обновляется автоматически
- Поля `id`, `created_by`, `created_at` и `tkp_num` защищены от изменения при обновлении
- **Числовые поля оборудования** (БКТПБ, КТПБ, КТП, КСО-393, КСО-204, К-104, К-104М, ЩО, ПКУ, ПУС, ПАРН) валидируются в диапазоне 0-100, значение по умолчанию 0
- **Поле city** в модели Manager — текстовое, по умолчанию "ив"
- **Поле server_address_slug** в модели Company — текстовое, по умолчанию "/02_сторонние_заказчики"
- **Inline-формы**: при создании компании — возможность создать директора и должность; при создании контрагента — возможность создать компанию, директора и должность

## Подготовка к ИИ

- Все данные о запросах логируются и сохраняются для будущего обучения модели
- API возвращает данные в JSON формате (готово для подключения ML-сервиса)
- Структура данных позволяет добавить поле для AI-предсказаний (например, `predicted_category` или `ai_recommendation`)
- История статусов и менеджеров в запросе помогает анализировать маршруты обработки
- Информация о директорах и компаниях позволяет анализировать структуру и взаимодействия
- **Поле tkp_num** может использоваться как уникальный идентификатор для ML-аналитики

## Приоритет функциональности

1. **Авторизация** (главная страница с формой входа, редирект на dashboard)
2. **CRUD** для запросов, контрагентов и менеджеров
3. **Модели директоров и должностей** (базовые данные)
4. **Автоматическое заполнение** полей менеджера, даты, компании, создателя и TKP номера
5. **Числовые поля оборудования** с валидацией 0-100
6. **Inline-формы** (создание связанных сущностей без перехода на другую страницу)
7. **Базовый дашборд** и фильтрация
8. **Формы создания/редактирования**
9. **Страница деталей запроса**
10. **Логирование и аудит**
